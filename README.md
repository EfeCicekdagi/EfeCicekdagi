## 🚀 Featured Projects

### 🔍 AML Entity Matching System
Developed an end-to-end entity matching pipeline that compares company names extracted from EFT descriptions with watchlist records. The system combines trigram, full-text, vector, fuzzy matching, and cross-encoder reranking methods to generate explainable risk scores and alert decisions.

### 🏗️ Marketing Lakehouse & Analytics Platform
Built an end-to-end data platform on Databricks using the Medallion Architecture. The project includes Bronze, Silver, and Gold layers, incremental ETL pipelines, audit and data-quality controls, a dimensional data warehouse, Data Marts, dashboards, and AI-oriented analytical components.

### 🌳 Semi-Structured Data Parser
Created a recursive PySpark pipeline that parses complex JSON-like data, discovers root-child relationships, expands nested objects and arrays, and transforms the resulting structure into a visual tree model.
